# 降智检测：AI 动态出题

原「鹈鹕测智」界面统一改名「降智检测」。数据库、内部类型和 `/pelican-*`
API/页面地址保持兼容；历史动画里的鹈鹕及固定题目不会被改写。

## 配置

智能运维 → 降智检测 → 新建/编辑分组测试：

- 被测分组/模型仍决定谁作答，与出题模型相互独立。
- 开启 **AI 动态出题**，选择本站已有 API Key、出题模型，填写自定义出题提示词。
- 默认提示词：

  > 帮我生成个提示词，关于动物、昆虫、常见动漫角色做某个动作、运动的场景，你的输出必须严格按照这个示例的格式输出：创建一个 HTML，内容是 SVG 绘制一个鹈鹕骑自行车的 2D 动画，你不需要任何测试

- 兜底题库可配置 1–20 个题目，每题最多 32000 UTF-8 字节，总共最多 128000 字节。
- 每份并行样本先出题一次，再获取作答账号槽位。出题成功直接使用，不抽兜底；
  超时、HTTP 错误、拒绝、空输出、截断、代码块/实际 HTML 等无效输出时才随机选一个兜底。
- 作答失败的换号重试沿用本份样本的实际题目，不重复出题；不会因作品作答失败而换成兜底题。
- 关闭 AI 动态出题时直接随机使用题库。历史计划不自动启用 AI，旧单题保持兼容。

## Key、计费及保护

只保存 `question_generator.api_key_id`，不在配置/结果里复制密钥。
Key 每次从数据库读取，经固定本机 `/v1/chat/completions` 入口发起普通 SSE 请求；
不经过环境代理，不使用外部站点 URL，不跟随重定向。
普通鉴权、余额/订阅、Key 配额、IP、模型策略、限流和零缓存保护仍适用。
出题调用最多等待 90 秒，输出 token 上限 2048，没有额外的应用层重试。
Key 删除、停用或过期后出题失败，使用配置的兜底；保存同一 Key 的旧计划不要求重新授权。

**出题会正常使用该 Key 的余额和配额**，调用在使用记录中可见。
本页「测试消耗」仍只统计作答账号的成本，不包含出题 Key 的费用。
因此不要把本页汇总当作整个出题+作答流程的总账。

## 记录与 API

结果 `pelican_config.prompt` 保存本次实际题目，`question_source` 为 `ai` / `fallback`
或 `pool`（旧固定题不新增此字段）；出题失败记录安全错误码及生成耗时。
测试记录标明题目来源，作品预览可展开查看实际题目。
不保存上游错误原文或传输错误中的凭据/URL。

新增管理员只读端点：

`GET /api/v1/admin/pelican-group-tests/generator-keys?q=名称&selected_id=ID`

最多返回 100 个名称匹配 Key，以及不在结果里的已选 Key。
只返回 ID、名称、所有者 ID、状态和可用标志，不返回密钥。
原分组测试输入新增可选 `question_generator` 和 `fallback_prompts`，保存于既有 JSONB，
无数据库迁移、无 JWT/TOTP/密码轮换。只有管理员可设置所用 Key。
